# AUREL art direction

Ivory, terracotta, blue water and a very large Cormorant Garamond wordmark. The aperture starts as an offset oval revealing a Mediterranean coast, expands with native scroll and becomes the environment around the opening copy. One progress value controls the mask, image framing, shade and copy colour. The page then releases into unpinned editorial layouts, asymmetrical photography, room tabs and a terracotta daily rhythm spread.

The brand is an original fictional retreat. Photography is illustrative and is not evidence that AUREL operates the depicted properties. No invented awards, testimonials, prices, customer counts or real bookings.

Desktop and mobile use different aperture radii and type scales. The hero has no autoplay slideshow, mandatory timer or wheel interception. Motion is reversible. Reduced motion opens the aperture fully and leaves all practical content available.

Acceptance targets: room tabs, local itinerary, download, navigation, contrast, focus, narrow screens, reduced motion and no external required resources. Build and source verification alone do not establish visual quality. The integrator must review actual browser compositions and movement.

## Quality iteration

The earlier hero source was 1400 × 2108 pixels, with 1200px and 1400px supporting photographs. New derivatives use verified originals up to 3200px wide, with no enlarging. A desktop crop preserves the view while avoiding a needlessly tall decoded texture. Natural image colour replaces CSS saturation filters.

The new second scene is a stack of large physical photographic prints turning into place in perspective. This is deliberately distinct from a horizontal filmstrip. One native progress controls all print transforms and the heading. Images stay readable when motion stops; selecting the visible print opens a large local view. Reduced motion exposes a normal three-image gallery.
